# Ide jönnek a rajzok

Tedd ide a PNG-ket **pontosan** ezekkel a nevekkel — a játék magától átveszi őket,
kódot nem kell módosítani. Amit nem teszel be, azt a kódból rajzolt placeholder
viszi tovább.

A teljes lista, méretekkel: lásd a `emma-story/README.md`-t, vagy nyomj `T`-t a
játék címképernyőjén.
